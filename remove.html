Remove student. Type the name of the student to take away and press remove. Only a signed-in admin may remove one, so the page asks the backend for permission as it loads — the remove button stays grey until it has answered — and asks again when the button is pressed. The name is read back to you once more, and the question is asked before anything happens: Yes takes the student away for good — it cannot be undone — and No leaves them alone. Nothing is done while the question stands. The backend has no route that takes a student away yet, so an answered Yes is met with that, and the account stays where it is.
